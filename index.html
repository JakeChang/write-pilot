AI 驅動的
Markdown 寫作工具

Write Pilot 是一款三欄式寫作環境，整合 Markdown 編輯器、檔案管理與 AI 寫作助手，基於 SwiftUI + NSTextView 打造，專為中文寫作者設計。

下載 DMG 查看原始碼

需要 macOS 15.7 或以上 · Apple Silicon & Intel

功能特色

專注寫作的一切所需

Markdown 編輯器

NSTextView 核心引擎，語法高亮、即時預覽，完整支援中日韓輸入法（CJK IME），不會打斷你的輸入節奏。

AI 寫作助手

整合 Google Gemma 4 AI 模型，提供寫作建議、內容分析、來源偵測三種模式，串流輸出即時回饋，幫助你突破寫作瓶頸。

檔案樹管理

工作區資料夾瀏覽，支援新增、重新命名、刪除檔案與資料夾，一目了然。

即時預覽

WKWebView 即時渲染 Markdown，支援深色模式，所見即所得。

大綱與計畫

從 Markdown 大綱自動生成章節檔案結構，讓長篇寫作井然有序。

圖片拖放

拖入圖片自動複製至 images/ 並插入 Markdown 語法。

寫作統計

Menu Bar 即時顯示每日字數，區分手打與貼上字數，追蹤你的創作產出。

自動儲存與更新

1.5 秒防抖自動存檔，搭配來源追蹤 sidecar，不再擔心忘記儲存。內建 Sparkle 自動更新，永遠使用最新版本。

快速設定

設定 AI 寫作助手

1

取得 Google AI API Key

開啟 aistudio.google.com，使用 Google 帳號登入後，點擊「Get API key」→「Create API key」。

2

貼入 App 設定

開啟 Write Pilot → 偏好設定（Cmd+,），將 API Key 貼入對應欄位後按儲存。

3

選擇工作區資料夾

使用 Cmd+Shift+O 開啟工作區，選擇你的寫作資料夾，即可開始創作。

安裝指南

兩步驟開始使用

1

下載 DMG

前往 Releases 下載最新版本，開啟 DMG 並將 Write-Pilot.app 拖入 Applications 資料夾。

2

移除隔離屬性 （必要步驟）

由於 App 未經 Apple 公證，首次開啟前請在終端機執行以下指令，否則 macOS 會阻擋啟動：

xattr -cr /Applications/Write-Pilot.app
